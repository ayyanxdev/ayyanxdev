## ⭐ Featured Projects

### 🏥 Clinic AI Receptionist Pro

A 24/7 AI receptionist and appointment-booking system built for medical, dental, and veterinary practices — designed to stop after-hours inquiries from turning into lost bookings and to take repetitive FAQ handling off staff.

**What it does:**
- Holds multi-turn booking conversations with real session memory, not one-off replies
- Checks live appointment availability before confirming a slot, so double-bookings can't happen
- Uses guarded LLM function-calling so the AI can only book against verified backend data — it can't invent an appointment
- Gives clinic staff a settings panel to update hours, doctors, and policies without touching code
- Includes a staff dashboard with live KPIs (today's/upcoming/completed appointments, escalations) and flags urgent cases for a human

**Tech:** `Python` `FastAPI` `SQLAlchemy` `Pydantic v2` `Groq LLM` `SQLite`

### 📱 AI WhatsApp Business Assistant Pro

A business automation backend built for small businesses that get most of their customer inquiries through chat. It turns a conversation into a real business action — an order, a booking, a payment update — instead of just answering questions.

**What it does:**
- Detects intent (question, order, or booking) from an incoming message and routes it accordingly
- Tracks the full order and booking lifecycle in a real database, from creation through payment status to completion
- Feeds completed orders into business-level analytics on a live dashboard (customers, conversations, orders, bookings)
- Verified by an automated test suite — 29/29 tests passing at the current checkpoint
- Built with WhatsApp Cloud API integration as the next milestone; the backend, AI layer, and dashboard are already working end to end

**Tech:** `Python` `FastAPI` `SQLAlchemy` `SQLite` `Groq LLM` `pytest`
