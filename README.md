## 👋 About Me

I'm a **BSCS student** working toward becoming a strong software engineer, with a focus on **backend development, full-stack applications, and AI automation**.

I like building systems that solve practical problems: answering customer questions, managing bookings, connecting APIs, organizing data, and reducing repetitive business work. My projects usually combine a Python backend, a database, and clear ways for people or other systems to use it.

- 🐍 **Backend:** Python, FastAPI, REST APIs, SQL databases
- 🤖 **AI:** LLM integrations, AI assistants, RAG concepts, tool-based workflows
- ⚙️ **Automation:** webhooks, API integrations, n8n workflows
- 🌐 **Frontend:** HTML, CSS, JavaScript, React
- 🧪 **Engineering habits:** readable code, validation, testing, useful documentation

> **My goal:** build software that is understandable, testable, and useful outside a tutorial.

## ⭐ Featured Projects

### 🏥 Clinic AI Receptionist Pro
**An AI receptionist concept for clinics that need help handling common questions and appointment requests.**

- Supports multi-turn conversations for booking flows.
- Checks appointment availability against backend data before a booking is confirmed.
- Uses controlled tools/functions so the AI works with application data instead of freely inventing booking details.
- Includes staff-facing settings and dashboard features for appointment oversight and escalation.

**Built with:** `Python` · `FastAPI` · `SQLAlchemy` · `Pydantic` · `SQLite` · `Groq`

[![View repository](https://img.shields.io/badge/Explore%20Project-GitHub-181717?style=for-the-badge&logo=github)](https://github.com/ayyanxdev/clinic-ai-receptionist-pro)

### 📱 AI WhatsApp Business Assistant Pro
**A backend for turning customer conversations into trackable business actions.**

- Routes incoming messages toward questions, orders, or booking workflows.
- Stores conversation and business records in a database.
- Tracks order and booking progress and exposes data for business analytics.
- Designed for WhatsApp Cloud API integration; check the repository for the current integration status.

**Built with:** `Python` · `FastAPI` · `SQLAlchemy` · `SQLite` · `Groq` · `pytest`

[![View repository](https://img.shields.io/badge/Explore%20Project-GitHub-181717?style=for-the-badge&logo=github)](https://github.com/ayyanxdev/ai-whatsapp-business-assistant-pro)

### 🕷️ Python Product Web Scraper
**A tool for collecting product information and converting it into structured data.**

- Extracts product names, prices, discounts, images, and page links where supported.
- Exports results to CSV, Excel, or JSON.
- Intended to support both regular HTML pages and JavaScript-rendered pages, depending on the site's structure.

**Built with:** `Python` · `Web Scraping` · `Structured Data`
